Sobre Mim

Construo a ponte entre a lógica de programação e a estética de sistemas digitais. Meu trabalho consiste em estruturar a base técnica de aplicações web, garantindo que código robusto e escalável caminhe junto com uma experiência de usuário fluida. Utilizando tecnologias como React, Tailwind CSS e JavaScript para entregar produtos digitais consistentes e escaláveis.

Cada projeto é estruturado para responder diretamente às necessidades da sua operação, seja para digitalizar processos, otimizar fluxos de trabalho ou lançar uma plataforma comercial no ambiente digital.

Sistema Operacional de Orçamentos e CRM Comercial – Polibalbino

Desenvolvimento e implantação de um sistema operacional e CRM personalizado para a Polibalbino. A plataforma automatiza a geração de orçamentos a partir de pedidos vinculados à tabela de preços e ao estoque em tempo real. Além de otimizar a rotina operacional da equipe de vendas, o sistema centraliza o histórico comercial e gera métricas estratégicas para orientar a tomada de decisão da diretoria.
